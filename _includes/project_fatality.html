Predictive Machine Learning Model for Fatal Accident

Project Overview

This project develops a predictive model to estimate the likelihood of fatalities in traffic accidents in Toronto. It leverages Toronto Collision Data (available here) to analyze key factors such as location, vehicle type, and time. Various machine learning models including Logistic Regression, Random Forest, Decision Tree, Support Vector Machine (with estimators Support Vector Classification), and Neural Network are applied to enhance the accuracy of the predictions.

Data Exploration

1. Explored the all columns of the dataset.

2. Performed feature selection using various techniques:

  • Chi-Square Value Score
  • Correlation Heatmap
  • Scatter Matrix
  • Histogram Data
  • Missing Values
  • Data Analysis

Data Cleaning

1. Missing Values Handling: Removed columns where more than 80% of the data was missing. Deleted rows in columns with less than 3% of missing values.

2. Encoding Categorical Variables: Grouped data under the same categories.

3. Scaling Numberical Features: Utilized Sci-kit learn preprocessing to perform min-max scaling of the data.

4. Deriving New Feature: Created additional context, such as 'weekend' feature derived from the date column.

Model Building

1. Split the data into training and testing subsets.

2. Utilized Sci-kit learn library to implement various machine learning models including Logistic Regression, Random Forest, Decision Tree, Support Vector Machine, and Neural Network.

3. Ran each model and listed their accuracy scores for comparison.

Prediction Result

1. Integrated all models with a Flask API to predict fatalities, offering the following features:

  • Users can predict fatalities by selecting data input.
  • Users have option to choose the classifier they are interested in.
  • The prediction results are displayed to the users.
