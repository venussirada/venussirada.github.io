Spam Detection

Data Exploration

1. Explored the 57-column dataset of KSI (Killed or Seriously Injured) dataset.

2. Performed feature selection using various techniques:

  • Chi-Square Value Score
  • Correlation Heatmap
  • Scatter Matrix
  • Histogram Data
  • Missing Values
  • Data Analysis

Data Cleaning

1. Handle Missing Values: Remove the columns which more than 80% of data were missing. Remove rows for columns with less than 3% of missing values.

2. Encoding Categorical Variables: Group data under the same category. And converted certain attributes into binary format such as 'Yes' and 'No'

3. Scaling Numberical Features: Adapted Sci-kit learn preprocessing to perform min-max scaling of the data

4. Derived new feature to provide more context such as creating a weekend feature based on date column

Model Building

1. Splited data into training and testing set

2. Implemented machine learning models including Logistic Regression, Random Forest, Decision Tree, Support Vector Classification, Neural Network by leveraging from Sci-kit learn

3. Ran and listed the accuracy score of all models.

Prediction
