Spam Detection

Project Overview

This Python-based project focuses on developing a model to identify spam comments on YouTube, addressing the challenge of excessive spam comments across the internet.

Data Exploration

Loaded and explored data using python to analyze the data format through various methods:

  • Analyzed dataframe information (shape, info, describe, and head of the data).
  • Performed URL identificatio. As URLs are often used in spam comments, identifying the URL is useful for spam detection.
  • Conducted emoji identification.
  • Identified Non-English and non-numeric text.
  • Filtered out unrelated features. Drop columns such as comment_id, author and, date that were not relevant to the analysis.

Data Preprocessing

Performed data preprocessing using methods such as stopwords, WordNet, and Punkt from NLTK and performed below steps:

  • URL replacement
  • Lowercase text
  • Punctuation mark removement
  • Text tokenization
  • Word stemming
  • Word lemmatization

Downscale the Transformed Data

Weighted each vocaburaly against the total words by transforming data using TF-IDF (Term Frequency - Inverse Document Frequency).

Shuffle Dataset

Shuffled all rows in the dataset to reduce bias in the data order.

Training the Dataset by:

  • Split the dataset into training and testing subsets.
  • Trained the model using the training subset.
  • Divided the testing dataset into 5 equal parts using the cross-validation method.

Test the Data

  • Input test data consisting of 4 non-spam and 2 spam comments.
  • Ran the prediction model.
